# F1 Race Analytics

Учебный dashboard для анализа прошедших гонок Формулы-1 по OpenF1 API с серверным слоем для GigaChat.

## Возможности

- выбор сезона, этапа и сессии Race;
- итоговая таблица, топ-3 и краткая аналитика;
- карточка пилота с кругами, пит-стопами, шинами и инцидентами;
- сравнение двух пилотов;
- SVG-карта трассы по координатам OpenF1 `location` с downsampling на backend;
- блок Race Control и аккуратный анализ возможных проблемных моментов;
- погодные графики;
- ИИ-чат GigaChat без передачи ключей на клиент.

## Запуск

```bash
npm install
npm run dev
```

Frontend доступен через Vite, backend API — на `http://localhost:3001`.

## Переменные окружения

```env
GIGACHAT_AUTH_KEY=
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat
PORT=3001
```

Если ключ GigaChat не задан, чат вернёт понятное сообщение об ошибке.

## Демо-данные и пустой OpenF1

Если OpenF1 возвращает пустой массив (например, для будущего сезона) или API временно недоступен, frontend автоматически показывает встроенный демо-набор: календарь, пилотов, результаты, круги, пит-стопы, шины, погоду, инциденты и координаты карты. Это нужно, чтобы на защите проекта интерфейс не выглядел пустым.
